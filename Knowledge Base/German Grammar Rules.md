| --- | --- | --- | --- |
| **Nominative** | Masculine | der schöne Hund | ein schöner Hund |
|  | Feminine | die schöne Katze | eine schöne Katze |

|  | Plural | die **schönen** Hunde | keine **schönen** Hunde |
| **Accusative** | Masculine | den **schönen** Hund | einen **schönen** Hund |

|  | Neuter | das schöne Haus | ein schönes Haus |
|  | Plural | die **schönen** Hunde | keine **schönen** Hunde |

# Possessive Pronouns

| Person | Nominative |
| --- | --- |
| **ich** (my) | mein |
| **du** (your, sg.) | dein |
| **er** (his) | sein |
| **sie** (her) | ihr |
| **es** (its) | sein |
| **wir** (our) | unser |
| **ihr** (your, pl.) | euer |
| **sie** (their) | ihr |
| **Sie** (your, formal) | Ihr |

# Personal Pronouns

| Person | Nominative (Subject) | Accusative (Direct Object) | Dative (Indirect Object) |
| --- | --- | --- | --- |
| I | **ich** | **mich** | **mir** |
| you (sing.) | **du** | **dich** | **dir** |
| he | **er** | **ihn** | **ihm** |
| she | **sie** | **sie** | **ihr** |
| it | **es** | **es** | **ihm** |
| we | **wir** | **uns** | **uns** |
| you (pl.) | **ihr** | **euch** | **euch** |
| they | **sie** | **sie** | **ihnen** |
| you (formal) | **Sie** | **Sie** | **Ihnen** |

# Indirect Questions

| Question Type          | Question                       | Indirect Question                                              |
| ---------------------- | ------------------------------ | -------------------------------------------------------------- |
| Yes / No Question      | Habe Sie noch ein zimmer frei? | Ich möchte gern wissen, **ob** sie noch ein zimmer frei haben? |
| Question with wh verbs | Wer ist das?                   | Können Sie mir sagen, wer das ist?                             |
